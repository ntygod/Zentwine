# Zentwine · 众弦

让人与不同模型协同构建、交付和持续改进软件。

Zentwine 的目标是一个拥有原生需求、项目和 Coding 工作台的团队研发平台，支持 Claude Agent SDK、Codex 等运行时，以及真正的异构多模型协作。

## 当前状态

本仓库处于产品与工程规划阶段，尚未实现产品功能。详细开发计划通过独立分支和 Pull Request 评审维护。

成熟产品范围覆盖产品发现、需求、设计、架构、项目组合、多模型执行、独立 Coding 工作台、质量、发布运营、知识、治理和扩展生态。实施分阶段，不缩减终态。
