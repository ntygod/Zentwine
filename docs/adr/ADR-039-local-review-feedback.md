# ADR-039：本地 Git 核对后的渐进式意见读取

状态：Accepted（限定本地读取设计）；日期：2026-09-29；关联 Issue #77，父 #63。普通技术决策，不是独立第三方认证。

## 背景

A–F已交付本地仓库读取、比较、Studio查看及意见合并。浏览器只检查导入声明，不能证明报告内容来自本机Git；coding工具也缺少按文件读取意见的统一终端入口。

## 决定

新增独立只读CLI，仅读取明确交接目录中的comparison.json和review-notes.json。复用client公开会话/解析器，而不是维护第二份v1语法。原报告字节摘要绑定继续成立，不规范化原JSON后重新算绑定。

通过既有Git端口重新比较报告声明的两个完整提交及携带的单文件detail，再比较严格解析后的规范投影。工作区种类属于原运行环境，不纳入对象内容一致性；远端来源与作者身份仍不认证。原报告合法但对象、路径、大小或hunk有误时拒绝，不以摘要自洽替代Git读取。

默认仅返回路径与类型计数；显式--path才附意见原文与自填署名，永不自动附原报告代码片段。使用单行JSON，并对终端显示控制字符作无损Unicode转义；不输出可执行命令或把意见视为授权。

固定文件名和目录描述符限制输入读取范围；普通文件、单硬链接、大小、身份复核、总期限、取消及清理均失败关闭。复用Git既有禁止网络、过滤器和hooks的路径。不改旧解析器、报告格式、Git端口、旧测试或必需门禁。

## 不作出的保证

这是本地内容一致性观察，不是当前任务基线校验、当前工作树clean证明、持久Review、远端签名或执行许可。不同仓库含相同对象也能匹配；意见作者和真实性不能由本核验推导。未携带的文件正文不额外核验，意见自身也可能包含代码。

目录/文件采样不是原子快照，不能排除所有恶意同用户竞态或返回后变化；普通文件I/O可能阻塞，O_NONBLOCK不构成硬资源隔离；字符串和stdout副本无法保证擦除。调用方负责权限、沙箱和用户所期望的base/head。

## 验证与回退

真实临时Git→原CLI→原意见/合并接口→本CLI往返；结构自洽伪造、错配、固定文件类型、部分读取、取消/迟到、输入替换和子进程/描述符清理。完整旧回归及精确CI仍必需。回退新增脚本/测试/指南即可，原v1文件和Studio行为不变，不回写用户仓库。

官方语义参考：[Node File system](https://nodejs.org/docs/latest-v24.x/api/fs.html)、[Git cat-file](https://git-scm.com/docs/git-cat-file)。本地资源读取仍以真实回归及 [使用指南](../development/local-review-feedback.md) 所述范围为准。
