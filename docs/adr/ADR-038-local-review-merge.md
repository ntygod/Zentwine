# ADR-038｜多份本地意见的显式预览合并

日期：2026-09-29｜状态：接受（限定本地意见增量）｜Issue #75，父 #63。

## 问题

E支持单份意见交接，但已有意见时拒绝导入，团队收集多份反馈只能人工重录。不能直接拼接数组或以同ID自动覆盖，因为不同内容、错报告与聚合限额都可能被忽略。

## 决定

新增纯client预览与应用接口，复用E的已登记会话、v1输入解析、不可变意见验证与标准导出。逐份输入必须绑定完全相同字节的原报告，不扩展可信来源声明。原空集导入路径保持不变。

按ID对齐：全字段相等才去重；不同ID不做文本相似合并。同ID内容不同显示冲突，并要求每个冲突恰好一次显式current/incoming选择。保持原位置，新ID依输入顺序追加。没有默认选择、自动改ID、自动批准或作者认证。

预览冻结全部快照并在WeakMap登记会话和标准化当前集。应用核对预览来源与当前集完整内容/顺序，再验证全部选择，生成完整结果并通过原100条/512KiB导出约束。任何错误只抛统一错误，原数据不变；这是本窗口内存基线，不宣称持久CAS或恶意同进程沙箱。

UI沿用原FileReader、10秒截止和代次控制，不建立第二套读取控制器。预览组件只负责分页、展示和冲突选择。取消、替换、清除或卸载丢弃预览；迟到读取不得恢复。预览不撤销当前下载；成功应用才使旧下载失效。未添加草稿在取消时保留，确认成功时清空。

## 取舍与回退

不选择自动最后写胜出：自填署名、ID和文件没有可靠时间/身份。不支持保留两份同ID并静默重命名，避免伪造溯源；用户可取消后显式另写新意见。不引入v2文件格式、服务器数据库、网络或浏览器自动存储。

预览可以包含两个各512KiB输入；条目最多各100，DOM每页10。最终JSON转义和路径开销仍可能超限，所以必须在应用前重新序列化，失败允许重新选择较短版本。

范围仅为本地反馈汇总，不能解除持久、远端权限或真实运行宿主前置。移除新接口、预览组件与接入即可回退；既有v1文件保持可读，不改写用户磁盘文件。
