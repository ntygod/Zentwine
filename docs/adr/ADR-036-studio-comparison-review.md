# ADR-036｜Studio 导入报告与代码差异审阅

状态：Accepted（限定本地导入界面）｜2026-09-28｜Issue #71，父 #63。

## 背景与决定

C 已通过 PR #70 提供固定提交对比 CLI，但团队尚不能在 Studio 阅读结果。本轮复用 CLI 原有成功 JSON 作为显式本地输入，增加 client 严格解析与共享 UI 审阅组件；不新建本地 HTTP 文件服务，不修改原 CLI/历史比较语义，不提前建设持久 Review、编辑器或执行宿主。

UI 先让用户选文件，再点击导入，最后点具体路径展开。一次仅保留一份报告；替换先清除旧上下文，不将多份报告合并成可信证据链。仅携带 selected 的路径有正文，其他路径提示回到 CLI 显式生成单文件报告。二进制、符号链接和 gitlink 明确不渲染。

## 信任与边界

报告里的 source/local_git、SHA、统计与正文都是不可信声明。解析检查版本、对象形状/路径关联、分类、计数、hunk 行号与统计，但浏览器没有核验实际 Git 对象、来源身份或权限。返回投影固定 trust=unverified_import，不带批准或执行能力；页面持续标识来源未认证。构造一个结构自洽的伪造报告仍可能通过，不把导入成功当认证。

JSON 使用已有拒绝重复解码键的有界解析器；为报告新增独立 100000 节点/16层预算，原 runtime 的 8192节点/16层完全保持。导入最多4MiB/2000条目/4000差异行，且文本载荷延续C的1MiB上限；这是 UI 接收子集，不改变 CLI 上限。按50文件/100代码行分页，不一次构建整仓DOM。

代码及名称以 React 文本节点显示，无 HTML 注入、自动链接、下载、模型提示词或终端执行；控制/BOM/双向字符仅在呈现时可见转义，原始值不改写。格式检查无法证明正文与对象ID吻合。

FileReader 有10秒读取截止；清除、替换、取消、关闭及卸载会取消自身读取并使旧代次失效。收到的ArrayBuffer清零；JS字符串、File/平台副本及浏览器内部对象不保证可验证擦除。页面不写存储或上传，但既有 Studio bootstrap 仍是本地只读请求。

## 验证与回退

真实临时 Git → 原 CLI → 新解析器；Chromium 覆盖显式展开、拒绝/恢复、恶意文本、取消与迟到、键盘、分页、主题和窄屏。取消/竞态用有说明的浏览器读时序注入，不冒充真实恶意文件系统。

原测试、依赖、迁移及工作流保持；完整 CI 和制品绑定精确候选。回退新增 client/UI 与入口即可，不涉及用户仓库或数据迁移。原 #32/#35/PR33 与父#63/#46/#40/#25 不解除。
