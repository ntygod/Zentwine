# ADR-027：显式有界运行事件字节流

状态：Accepted（限定传输消费者；不解除持久联调前置）。关联ZT12-01-A3、Issue #51；前置契约/观察器分别见ADR-025/026。

## 决定

在client增加一次性原生ReadableStream消费者，不新增URL/API/授权槽位。使用严格UTF-8、LF/CRLF有界分帧，内部有限JSON读取器在覆盖前拒绝重复键，再使用既有wire与观察器。有限整数token配置明确拒绝舍入、小数和指数，不修改原协议或旧消费者。

观察器保留实例内合法前缀；分片不改变语义。流一旦产生缺口/冲突/未知结果即要求独立inspect，不在同一响应上自动补读。只有完整帧+终态报告+EOF称响应ended，不能称任务成功或进程已停。

实例close/Abort同步清空本地数据并取消reader，不等待底层cancel完成；每次读取的等待信号按次结算，防止单字节块造成Promise反应累积。限额同时覆盖原始字节、JSON帧、空块以及既有观察器规范化容量。

## 代价和拒绝方案

不使用JSON.parse直接覆盖重复属性，不默认修复UTF-8或接受未终止末行；与宽松NDJSON发送方不兼容，需要宿主按此配置编码。拒绝自动重连/重试，不把HTTP GET混入构造函数；严格补读需要新授权和新实例从头构建。它不替代鉴权网关、持久inbox、增量游标或执行宿主。

## 验证与回退

原生Web流的全部分片与真实本机HTTP测试分别证明帧语义及传输消费，不冒充网络分片控制或真实模型兼容。保留原观察器/协议/权限/迁移/工作流/依赖锁。发生回归可停止使用新增公开入口并回退本增量，原A/A2接口无变更，无数据库回退需求。
