# ADR-031：先把交接检查接入 Studio 的显式本地入口

状态：接受为 ZT12-01-A7 限定实现决定；Issue #59。最终验收与合并以对应 PR 为准。

A 至 A6 已提供协议、事件读取、内容校验和多输入整批准备，但 Studio 尚无可操作入口。当前版本持久化与宿主前置未解除；不能为了界面演示虚构 Run 或默认加载成功 Fixture。因此增加独立本地检查台，消费用户显式选中的计划、事件文件及产物文件，不访问组织数据，不启动任何执行。

复用 A6 而不复制报告或摘要判定逻辑。新的 JSON 入口仅定义诊断封装，严格解析后交给现有 RuntimeInputBundle 完整覆盖预检；不扩张 wire1.0.0。组件属于共享 UI 包，复用其合法 client 依赖；Studio 仅负责首页入口与局部样式，不新增依赖或绕开包边界。

检查按钮前必须完成所有文件映射。先等全部报告通过再读取产物；结果面只显示元数据，成功后也关闭读取器释放内容，不提供领取/导出/执行能力。取消、关闭、卸载与重置隔离旧异步结果；源文件与已交给浏览器平台的副本不承诺安全擦除。

代价：此页不连接团队持久状态，需要手动映射文件，不能替代生产协作工作区。收益：已有模块首次可由用户直接操作，真实浏览器验证 Web Streams、Web Crypto 和取消路径；结果仍明确标识来源未认证与无授权。

回退：撤销新增入口、组件、JSON适配入口及样式，不涉及数据库迁移或存储数据。父 #46 的持久联调、宿主/适配器消费及原 #35 审查条件保持。
