# ADR-037｜原报告绑定的本地文件意见交接

日期：2026-09-29｜状态：Accepted（限定本地增量，实施者技术决定）｜Issue #73，父 #63。

## 问题

Studio 已能读取 C 的比较报告，但阅读后的文件意见不能交给下一名成员或 Agent。直接按文件名或提交对附带意见，可能误套到内容不同的导入报告；当前浏览器又没有来源认证、组织权限与持久 Review。

## 决定

独立意见文件只保存 schema/scope/trust/authorization、原报告完整 UTF-8 字节 SHA-256、两侧 commit/tree、对象格式及文件级意见。会话先使用原解析器完整验证报告，再通过 Web Crypto SHA-256 计算字节绑定；不规范化空白或 JSON 键顺序。原报告需单独交接，重新格式化也视为不同输入。摘要不是 Git 对象认证或签名，结构自洽的伪造报告/意见仍可能通过。

意见分类仅为问题、建议、疑问。署名为自填文字，ID 仅用于该意见集去重；不创建批准、负责人身份、撤权事实或可信审查历史。意见路径必须在当前报告变更清单中；不声称行级锚定，不检查意见是否正确。

client 负责严格解析、不可变快照与序列化；UI 负责草稿、读取生命周期和显式下载。用户先准备文件，再点击下载链接；不自动上传或保存浏览器存储。已有意见时不允许导入覆盖或自动合并；先下载、清除，再导入其他意见集。切换路径清理未添加草稿；替换报告和卸载销毁会话。导入意见也清理未添加草稿。

最多100意见、单条正文4000字节、署名120字节、文件及标准导出524288字节；每页最多10意见。复用独立报告 JSON 读取预算100000节点/16层，旧runtime预算不变。重复键、额外字段、错配绑定、未知路径、重复ID及非法Unicode整份拒绝，不回显拒绝输入。

FileReader延续10秒截止和代次隔离；取消、清除、卸载后的迟到结果不能重建意见。原报告摘要异步结果也受原读取代次控制。Owned byte buffers 清零，对象URL在意见集变化/清除/卸载时撤销，单会话最多一个；浏览器内部副本、JS字符串与下载到磁盘的文件不承诺擦除。

## 不采用的方案

不在localStorage自动持久化，不增加本机文件HTTP服务；不把意见写入GitHub，不使用报告哈希代替作者签名。不建立通用Review数据库，也不借本地功能解除ZT03-02-B前置。

## 验证与回退

真实Git/CLI源报告、独立Node摘要、跨会话意见往返与错配正反例；真实Chromium下载及重新导入、草稿/文件切换、取消/超时/迟到、URL回收、纯文本显示与窄屏。旧比较及runtime测试保留。回退新增client/UI与接入，不回写Git、不回收用户已下载文件。

Web API语义参考：[W3C Web Crypto digest](https://www.w3.org/TR/webcrypto/#SubtleCrypto-method-digest)、[W3C File API对象URL生命周期](https://www.w3.org/TR/FileAPI/#lifeTime)。标准参考不是本功能的安全认证。
