# ADR-040｜任务基线与审阅交接字节的显式锁定

状态：Accepted（限定本地读取）；关联 ZT18-01-H / Issue #79，父 #63。日期：2026-09-29。

## 背景

G 能证明导入报告的规范投影与指定本地 Git 一致，但不能判断它是否属于调用方本次任务。默认摘要与后续按文件读取之间，交接目录也可能换成另一份仍然有效的意见。不能把本地对象存在、当前 HEAD 或自填署名当作任务授权。

## 决定

为原 `inspectRepositoryReview` 增加可选 `expected`，四项必须完整：baseCommit、headCommit、reportSha256、notesSha256。CLI 对应四个 `--expected-*` 参数。全部省略保留 G 的观察语义；部分、未知、重复或非法配置拒绝，不静默退回未锁定模式。

首次 await 前复制普通对象的自有可枚举数据属性，不调用 getter 或字符串强制转换；只接受同一 Git 算法长度的完整小写提交 ID 与64位小写文件摘要。对象反射不是同进程恶意 Proxy 沙箱。

输入按原固定名称与限额读取。先匹配两份原始 UTF-8 文件字节摘要，再匹配成功报告声明的 base/head；错配在 Git 子进程和任何意见披露前整次拒绝。即使四项一致，原格式、意见绑定、本地 Git 复算、采样/清理、期限和取消检查全部继续执行。

成功仅在提供四项时增加 `feedback.expectation_verification: matches_explicit_pins`。未提供时不出现此字段；没有新增批准、Run、写租约或身份声明。退出码0必须与该字段及原本地匹配状态一起检查。

## 取舍

- 使用原始文件字节，而非规范化后的 JSON：排版、换行和意见顺序变化也必须显式重新确认。不会悄悄切换意见批次。
- 不从输入自动生成或更新期望值，也不自动选择 HEAD。base/head 来自任务约定，文件摘要来自独立确认；照抄不可信输入只能做到自洽。
- 不新增任务数据库、文件格式、签名机制或工作区状态读取。相同对象在不同仓库存在并不证明远端身份，固定历史版本不证明当前磁盘无修改。

## 验证与回退

真实 Git/CLI 往返、四字段错配、全部14种非空不完整CLI组合、调用方对象变化、两次读取间替换、格式和Git伪造、取消/期限/清理及无披露见 [验证报告](../testing/zt18-01-h-report.md)。原测试体、v1格式和必需CI保持。

回退可选参数与关联说明即可，无数据迁移、用户文件写入或已下载文件删除。使用见 [指南](../development/local-review-pins.md)。#32/#35/PR33及父#63的持久、远端与权限前置不解除。
