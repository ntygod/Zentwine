# ADR-015｜组织生命周期与联邦身份端口

状态：Accepted，限定本机可信开发范围；生产接入另行验证。任务ZT02-05，输入main@0655247417c1750d0c1111b8455919a9ddf61405。

## 决策

组织管理使用独立受限数据库角色，不把组织治理写权限授给普通API或Agent执行环境。沿用身份、策略、审批的协作锁顺序，管理员直接SQL不在此约束内。

访客不是新组织超级角色，而是membership.access_kind=guest、role=viewer，必须有访问期限；默认没有组织范围读取权。仅精确资源共享可读，更新、导出和Agent委派均拒绝。搜索先按权限过滤再取最多20条，不返回隐藏总数。

邀请只面向已由可信操作员登记的人类身份，绑定受邀者、邀请者版本、组织与设置版本及精确资源。秘密只存摘要。接受必须已有该身份的有效会话，同事务消费、建立成员关系、共享资源并轮换会话；不靠持有链接自动注册或冒名。不发送邮件，不自动回收或隐藏审计责任。

会话撤销按组织写入截止时间，不在持有组织锁时反向更新他人会话行。验证直接在数据库比较原生时间精度，避免JavaScript毫秒转换将新会话误判。撤销一个组织的会话不影响其他组织，单独撤销会话也不取消明确委派；成员状态或版本变化会使Agent与审批失效。

## 联邦接入边界

采用受信任SsoVerifier端口，只有服务器安装的适配器能验证外部证明。必须完整验证签名、issuer、audience、nonce/state、代码/PKCE、到期和重放，再向端口提交经验证的稳定subject。当前未内置外部验证器或浏览器OAuth回调，界面固定显示“未配置”。测试验证器明确为合成输入，不代表供应商登录认证。

外部主体仅由操作员显式映射到既有人类身份。映射按connection+subject及external_id精确区分，不基于邮箱/显示名自动合并。该映射赋予身份信任，操作员不能将不可信供应商映射到重要人类身份。已有映射的issuer/client不能原地变更，需要新配置和重新审核映射。

配置供应商的启用/停用同步使用规范化SCIM适配端口：显式机器凭据、外部主体、active、expected_version、request_id。它不是RFC7644的完整/scim/v2 API：未实现Groups、filter、Bulk、PATCH路径语法、ServiceProviderConfig或外部供应商认证。外部适配器负责协议转换；默认没有注册未知主体和任意改绑能力。

禁用映射在同事务撤销组织成员、提升版本、更新组织会话截止时间、撤销相关审批及邀请。旧Agent快照失效，WS逐消息重查并拒绝下一次访问。权威IdP可以停用最后负责人，不能为了可用性静默绕过停用；恢复依赖显式本机操作员。重新启用必须新同步并重新登录，旧凭据不复活。

## 安全与代价

设置和成员管理需要当前owner，最后负责人本地移除被阻止；管理连接器会话也按当前资格验证。机器同步凭据绑定配置版本、最长一天，轮换覆盖旧摘要。幂等请求返回历史回执而非重新施加旧状态。

当前本机HTTP Cookie没有生产Secure保证；组织级串行及连接/成员边界适合受控验证，不宣称高并发生产或完整SSO策略强制。日志不记录原始凭据、请求正文或搜索词。事件为生命周期记录，不是完整企业审计UI。

## 回退与依据

关闭组织模式可恢复原工作台壳，但0005的已安装访客/撤权约束继续由现有身份检查强制执行；不能通过关UI恢复旧权限。0005 down会撤销会话与访客后删除表，只用于明确销毁开发数据。旧0001–0004不改动。
