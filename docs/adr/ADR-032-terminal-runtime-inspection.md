# ADR-032：终端交接包只读检查

状态：接受为 ZT12-01-A8 的限定实现决定。Issue #61；最终验收与合并以对应 PR 为准。

## 决定

A7 用户必须逐项选择本地文件。增加终端命令，以明确目录和编号文件约定复用同一公开计划解析器与整批读取器，让团队可以在自己的工具链中复验交接包。不新增另一套验收状态机、不修改质量门禁、不把结果变成执行批准。

先只读打开全部必需文件且做类型/长度预检，所有报告通过后才读取产物正文；串行消费降低资源与错误定位复杂度，整批成功后不交付内容，只写一行机器可读结果。按原始计划字节摘要定位本次检查，输出序号而不是本机绝对路径和原始错误。超时、信号、内容拒绝和配置问题有不同退出码。

采用 Node 原生文件描述符和 O_NOFOLLOW/O_NONBLOCK，拒绝非单链接普通文件，比较打开前后、EOF 与结束时的描述符和路径元数据。Node 文档说明 O_NOFOLLOW 针对打开路径的符号链接、O_NONBLOCK 在可能时非阻塞；这些不是完整目录沙箱。参考：[Node 24 文件系统](https://nodejs.org/docs/latest-v24.x/api/fs.html)。不依赖手写文件系统快照或宣称抵抗恶意同用户竞态。

## 代价、验证与回退

编号约定不接受任意路径映射，降低灵活性但不把不可信计划当作磁盘读取指令；调用方须自行整理受控副本。描述符数量受原 8 生产者/16 输入上限限制。计时器为协作取消，不是强制内核终止；自动化环境另设进程级超时。Linux 为本次实际验收范围。

真实目录和子进程测试正常/拒绝/链接/FIFO/替换/超时/信号/清理，保留 A7 与所有旧回归。回退只移除新增脚本、测试与文档，不涉及存储迁移或依赖锁。父任务持久联调与真实适配器前置不改变。
