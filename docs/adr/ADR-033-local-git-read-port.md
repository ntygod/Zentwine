# ADR-033：本地 Git 固定提交只读端口

状态：接受为 ZT18-01-A 的限定实现决定；Issue #64 / PR #65，父 #63 完整仓库连接仍未完成。

## 背景与决定

运行交接目前已有字节校验和本地检查入口，但尚无读取真实代码基线的模块。本增量转向已有本地Git仓库，提供可导入的Node读取端口及元数据CLI。仅有本机用户显式调用，无组织绑定、网络、远端凭据、写操作或执行许可；原持久前置不解除。

固定HEAD和对象格式后读取递归NUL清单；读取指定文件必须提供完整预期提交，并从清单的对象ID读取blob，独立计算Git对象摘要。可见HEAD/分支/根目录身份变化时拒绝。支持裸仓库、linked worktree和sha1/sha256，不以工作区可变文件代替提交内容。

避免git status对未暂存内容的过滤器路径。仅通过禁用外部diff/textconv的index-only diff-index比较暂存区；未暂存/未跟踪/子模块工作树明确未检查，暂存gitlink仍参与比较。没有“工作区干净”结果。符号链接和gitlink只列元数据，LFS内容不自动获取。

## 取舍与信任边界

保守拒绝超限、非UTF-8文件名、非根目录、未出生HEAD和非普通blob。暂不分页或接受任意rev表达式，避免部分列表和自动回退掩盖问题。每次调用重读清单而不缓存，代价是额外Git进程和I/O。

端口放在scripts/lib，供Node宿主集成，不引入尚未存在的connectors包、前端Node依赖或修改依赖锁；未来服务端RepositoryPort接入时移动实现并保留测试。构造无I/O，不在页面打开时启动操作。

固定可信Git/环境和只读命令，不运行过滤器、仓库脚本或远端helpers；禁用可选锁/替换对象/懒加载/网络。取消杀死并等待当前Git进程组，但不声称原子文件系统快照、强制内核I/O期限、用户权限沙箱或远程Agent停止。元数据摘要不是授权、来源签名或代码安全证明。

## 验收与回退

真实Git临时库、固定提交原始文件、SHA1/SHA256、linked/bare、特殊文件名/模式、配置钩子不执行、损坏/超限/变更拒绝、信号/超时和输出失败验证。完整旧CI门禁保持。回退移除新增端口/CLI即可，不涉及数据库或用户内容迁移。父#63必须另外完成远端身份、私库授权、多项目/多仓库关系及真实持久联调。
