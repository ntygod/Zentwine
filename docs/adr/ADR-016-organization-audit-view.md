# ADR-016｜组织生命周期审计投影与分页边界

状态：Accepted（已实现范围的追溯记录）；2026-09-26。对应ZT02-06-B及C新增事件兼容。依据main `a30e7fe0257315fd7ad94c67c24a7b0772541d0f`的实际源码和PR #27/#28验收，不代表新建完整审计服务或独立第三方批准。

## 背景与选择

组织管理已经在业务事务内写入生命周期事件；需要负责人查看真实记录，又不能因新增历史页面扩大访客权限、泄漏原请求或把诊断日志当成业务事实。采用既有事件的白名单只读投影，不复制一套万能JSON审计账本。

原B九种事件和C两种应急事件逐一对应领域/契约定义。仅输出UUID引用、时间、类型、来源和目标。identity.linked/provisioned保留来源连接的归因，不以当前成员名回填历史操作人，不推断未记录的前后值。UUID仍是可关联标识，不能称匿名数据。

## 权限与一致性

每次查询复用可信会话、组织上下文和当前普通成员型owner资格；跨组织、降权、会话撤销及应急阻断按实际状态拒绝。共享资源权限不是组织审计权限，游标和前端可见性不是授权依据。

采用会话行及人/组织/成员/策略协作锁，组织事件写入取对应独占锁；历史读取取共享锁，并在返回前再次核验会话和owner。该协议避免同一组织较低未提交序号被高水位分页遗漏；绕过协议的管理员直接SQL不受保证。后续新增写入者须验证同一锁顺序，不能仅照搬序号字段。

## 分页与引用

0006为已记录事实补充独立audit_ref及组织索引，不改变原事件内容。按bigint序号而非时间戳或JavaScript Number进行键集分页，组织与类型过滤先于LIMIT。首屏高水位固定续页范围，刷新才读取新事件；这不是跨请求保持数据库MVCC快照。

游标用AES-256-GCM加密认证，密钥从实例随机秘密与会话摘要隔离派生，附加认证数据绑定组织、上下文版本、类型和limit；有效期为初始快照起15分钟。续页不续期，重启或实例切换要求刷新。每页仍重新鉴权。

选择临时实例密钥而不是长期共享密钥，是为当前单机开发范围降低秘密生命周期复杂度；代价是没有跨实例连续分页。此取舍不构成生产高可用认证。禁止为可用性在解密或权限失败时退回无绑定游标。

## 页面与错误

共享contracts严格解码，固定错误映射不回显驱动异常。无存储或无权限不能返回伪成功空列表。响应no-store，筛选/翻页前清空旧结果，组织切换/退出/权限错误丢弃旧结果和迟到响应，不写浏览器持久存储。

撤权不能收回已经返回的数据，页面不会凭空获知其他窗口的变更；后续请求重新鉴权。没有以页面截图替代数据库、HTTP和并发验证。

## 拒绝的替代方案

不开放原始事件表或任意JSON负载；不以普通成员拥有资源读取权推导owner权限；不把游标当永久许可；不按邮箱或当前显示名补写历史身份；不把全局自增ID、计数或偏移量直接暴露给浏览器。未采用分布式密钥服务、通用事件总线、完整保留策略或不可篡改存证，它们仍须后续专门实现和验证。

## 回退与未覆盖范围

停用页面/组织服务可保留数据。0006 down删除新增引用和索引，重新up会改变引用；先检查后续迁移，0007有应急历史后禁止down，不能跳过该限制。不承诺在线无损降级。

普通运行角色不能改写既有事件，不等于超级管理员不能修改；无保留清理和外部篡改证明。登录失败、资源访问、Agent执行、完整审批轨迹、通用对象历史仍未覆盖，ZT03-05不能据此验收。文件、预览和导出通道也未由当前投影实现。
