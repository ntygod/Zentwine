## 失败记录与修复

接续时的CI 36119683384中审批44/45通过。失败测试向Agent授权验证器只传resource.update，遗漏既有规则必需的resource.read，因而在到达预期的approval_required之前返回invalid_input。修正测试输入补上读取权限，拒绝断言和Agent安全限制保持原样，没有放宽验证器。

进一步自审发现领证、决定、显式撤销和通知响应在最后读取或写入等待期间仍可能过期。新增finish检查在返回记录后复核期限和当前会话；决定/领证保留请求及权限到期上界；通知读取结束前重查会话。四个新增场景通过pg_stat_activity确认真实锁等待，再跨过到期点，确认整次操作回滚或拒绝返回。既有消费路径也在事件/回执写入后复核期限。

其余验证覆盖：禁止自批、不同owner且拥有资源资格、明确区分政策预授权、显式deny不可覆盖、精确内容/环境/版本绑定、重复请求/决定/许可/消费、并发仅一次提交、持久回执、上游撤权原子通知、回滚与游标顺序。治理或消费的事件写入失败时，相关业务状态全部回滚，不报告虚假成功。

## 边界

许可只对人类scope的catalog.rename，不是公开生产认证、任意文件/代码/部署执行或Agent高风险提权。审批者暂为不同的有资格owner；细粒度审批角色后续实现。通知是按当前身份过滤的持久轮询，不是硬实时推送；自然到期和普通资源漂移由执行检查阻断，但不保证主动生成通知。

检查保证到最后一次事务内核验为止，不承诺数据库COMMIT或网络传输瞬间的硬实时时限。已提交动作或已返回数据不能撤回。直接管理员SQL不受合作锁约束；快照/制品摘要不是签名。没有OS级身份进程故障测试、新审批UI、模型调用、客户数据或生产部署；原浏览器及WS场景不是新的审批UI或审批WS协议验收。操作员仓储权限有测试，不声称所有手动CLI/psql步骤已端到端认证。
