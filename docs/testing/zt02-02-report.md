## 重点事实

- owner/member/viewer、精确reader/editor绑定、精确allow/deny、过期/未开始/撤销规则、跨组织、资源归属和环境条件均覆盖；未知动作含原型属性名一律拒绝。
- restricted资源不因组织owner身份自动开放；reader绑定不会解锁member的私人资源写入；显式deny和环境限制优先。
- 生产写入返回needs_approval但不执行；旧评估不能作为许可。目录写入同时核验目标版本与策略修订，四并发旧版本写入只有一个提交。
- 规则外键失败回滚策略修订；角色降级、成员/身份/组织停用后再次查询拒绝。
- 真实资源行锁等待期间，临时授权过期后拒绝写入。另一测试验证已持授权共享锁的写入先提交，身份撤销等待后提交，此后请求拒绝。没有声称撤权可以撤销已经完成的动作。
- WS握手检查Cookie、Origin和组织上下文；每条消息验证CSRF和当前权限。已建立连接上的注销、组织切换、成员撤销和新增拒绝均覆盖。二进制帧、超限负载、过多连接以及关闭服务清理均覆盖。
- 运行数据库角色不能配置授权、修改环境或停用身份。治理入口只对本机受信任操作员开放，不是租户自服务API。
