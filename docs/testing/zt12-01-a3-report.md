## 新增验证

80项新测试，76项原生Web流/内部JSON边界与4项本机真实HTTP。测试实际调用新读取器，不模拟它返回成功。HTTP载荷是wire合成Fixture，不是供应商调用、鉴权端点或生产业务数据。

| 类别 | 验证内容 |
|---|---|
| 分帧 | 所有两块切分、单字节、CRLF、转义键、Unicode合法解码后被封闭协议拒绝 |
| 严格JSON | 各层重复/转义同名键、特殊属性无原型污染、非法语法、安全整数、精确深度/节点 |
| 编码与容量 | 非法UTF-8/尾帧/BOM、帧字节/总字节/帧数精确边界、空块独立限额、重复收费 |
| 状态 | 固定org/run/attempt/来源、重放/冲突/缺口/unknown、终态EOF与坏尾部、原产物和用量语义 |
| 生命周期 | 预取消/提前关闭、待read与不响应cancel、迟到块、并发消费、锁释放、监听移除、固定错误 |
| 本机HTTP | 一字节write的chunked响应、无LF尾部、活跃响应Abort、实际socket断连且不重连 |

网络可能合并write；不宣称实际socket分片等于服务端write。字节切分确定性由原生Web流的显式切分独立验证。EOF/取消只描述本响应和本地读取，不证明远端工作完成/停止。
