## 验证重点

1. 子级资源、动作、环境、期限、深度、额度不能扩大，责任人不能改变。
2. 兄弟额度分配及成功工具调用并发不超卖；重复request_id不重复分配/扣减/写入。
3. 快照内容不可被运行角色改写、无原始凭据；重连仍有同一授权和回执。
4. 父撤销/祖先Agent停用/责任人、成员、组织、策略失效阻断后续调用。
5. 取得资源锁后自然过期仍拒绝，写入与额度/回执原子回滚。
6. Cookie/Origin/CSRF与Bearer严格分离，模型不能提供权威身份字段。
7. 真实loopback TCP有独立用例；其余HTTP场景使用Fastify inject，不声称压力测试。
