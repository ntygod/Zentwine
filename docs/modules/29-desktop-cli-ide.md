# ZT29｜桌面客户端、CLI 与外部 IDE 衔接

状态：Planned。负责人职责：客户端、开发工具、安全、执行。依赖模块：ZT12、ZT15、ZT17。对应蓝图：09.1、15.5、18.2；补充独立 Coding 入口。

## 目标

开发者可以长期停留在 Zentwine Studio，或在已有 IDE/CLI 工作，同时与管理端共享任务、上下文、执行和证据。平台只展示实际同步内容，不默认读取私人会话或所有未提交代码。

## 模型与连接

DeviceRegistration、LocalBridgeSession、WorkspaceBinding、DeepLinkIntent、ClientCapability、OfflineChangeProposal、SyncReceipt。深链只携带对象位置，不能携带长期 token；本地 bridge 限定 origin、一次性配对、作用域和设备撤销。

桌面候选 Electron，主进程/渲染/Runner 权限隔离；使用系统凭据存储、签名更新与严格 IPC。webview 中仓库内容不接触 Node 主进程能力。

## 完成条件

有独立桌面使用路径和至少一种外部 IDE 参考集成，CLI 可自动化但不绕过授权。具体客户端支持列表以实际测试版本展示。离线模型支持依赖兼容运行时，不承诺所有供应商可以离线。
