# ZT17｜Zentwine Studio：独立 Coding 工作台

状态：Planned。负责人职责：前端、编辑器、执行平台、质量。依赖模块：ZT04、ZT15、ZT16。对应蓝图：09、14.4、15；补充需求：Coding 可以单独打开且与管理端双向衔接。

## 产品完成体

独立 Web 窗口/标签，可设开发者首页；桌面和外部 IDE 由 ZT29 扩展。用户在同一界面读需求、编辑、使用不同 Agent、终端调试、预览、测试、看差异并提交评审。不是缩小的管理大屏，也不是单聊天窗口。

## 布局与数据

顶部：目标/交付/任务、spec/contract、仓库分支、环境、控制者、模式、预算和同步。左：文件/搜索/上下文；中：代码、diff、应用；右：Agent 计划/事件/决策/协作产物；下：终端、测试、调试。

WorkspaceView、EditorSession、OpenFile(base_hash,dirty)、Selection、PreviewSession、TerminalSession、RunSubscription、HandoffRequest。文件修改必须带基线 hash 与 lease epoch，冲突提示而非覆盖。

## 特殊路径

未关联任务的代码探索允许发生，但标 exploratory，正式提交时补工作包/授权/验收。不存在工作区时先显式创建，不在路由加载中隐式克隆和执行。

控制者切换与文件写入由后端/Runner 约束；不能只在 UI 禁用输入。本地私有草稿不上报绩效，用户可选择共享有团队意义的问题与成果。

## 完成条件

管理页面与独立 Coding 窗口双向一致；纯 Coding 使用者能完成大多数工作；工具/文件/预览权限经过反例测试；真实双基座节点可进入、观察、接手、继续和提交。原生工作台与供应商原界面不混同。
