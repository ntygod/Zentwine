# ZT27｜部署、可观测性与可靠性工程

状态：Planned。负责人职责：平台/SRE、安全、质量。依赖模块：ZT01、ZT02、ZT03、ZT15。对应蓝图：17.6、18、19。

## 范围

提供开发、托管、专属云、私有、混合与兼容离线部署。支持控制面、Worker、Runner、Verifier 分域，资源调度、日志/指标/追踪、备份、升级、故障恢复和应急手册。基础日志/隔离在 W1 开始，不等终态运维中心才建设。

## 数据和指标

DeploymentProfile、ComponentVersion、FleetMember、HealthSignal、BackupRecord、RestoreExercise、UpgradePlan、AuditExport。监控 API、事件、队列、租约、审批、预算、供应商和验证健康；高频 Token 不混入关键业务事件。

非功能目标见公共测试文档，是待实测提案，不是 SLA。统一 trace/correlation，默认脱敏；租户标签和内容访问分别授权。

## 风险与回退

多区域优先单主及显式转移，不默认数据库多主无冲突。升级先灰度，再扩大；运行时旧版本保留兼容直到安全收敛。数据破坏性迁移必须有前向修复或经验证备份方案，不能只靠回滚应用镜像。
