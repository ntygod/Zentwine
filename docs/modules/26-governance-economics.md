# ZT26｜成本账本、组织治理与商业管理

状态：Planned。负责人职责：后端、平台、安全、产品。依赖模块：ZT02、ZT03。对应蓝图：19、23。

## 目标

统一组织/项目/流程/执行/子执行的预算、成本、访问治理、保留和商业配置。预算原语必须在真实执行前交付，不等高级财务界面完成。基本权限、隔离和数据保护不能作为付费解锁条件。

## 数据和资金语义

Budget(scope,currency,period,limit)、Reservation(parent,amount,expires_at)、UsageEvent(provider_units,source_id)、LedgerEntry(debit/credit/reversal)、RateCard(effective_from)、Reconciliation、Entitlement、RetentionPolicy、DataExportJob。

金额使用明确币种与精确最小单位/decimal，不用浮点累计。预算预留、已记录用量、估计在途、供应商账单分开；不是每项都有可精确实时费用。

## UI 与策略

显示额度、已预留、已记录、估计在途、剩余可授权和对账差异。成本可按产品/研究/维护分类，不强制每 PR 成本，也不基于个人代码量收费。

供应商个人订阅、API 权益和自备 Key 按实际条款验证；不默认转售/汇集个人额度。Key 由凭据系统保护，账单/报表不含秘密。

## 完成标准

真实执行上线前 ZT26-01/02 必须通过；全模块完成要求对账、权益、保留和导出闭环。对外定价、合同和支付上线由负责人批准，不在本计划虚构最终价格。
