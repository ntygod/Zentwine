# ZT05｜产品机会、目标委托与实验

状态：Planned。负责人职责：产品、后端、前端、数据分析。依赖模块：ZT03、ZT04。对应蓝图：01、04、16。

## 产品边界

从用户信号形成机会、目标和可验证方案，允许无需开发的解决方法。模型生成假设不等于客户原话，模拟用户不等于真实研究，方案通过不自动授权生产修改。

## 数据与交互

Signal(source_uri,captured_at,consent,segment)、Opportunity(problem,evidence,assumptions)、Mission(scope_in/out,owner,success,guardrails,budget,delegation_ref)、RoadmapItem(intent/forecast/commitment)、Experiment(hypothesis,metrics,window,stop_rule)、ResearchArtifact。

页面：信号收件箱、机会详情、目标委托、路线图、实验工作台。API `/signals`、`/opportunities`、`/missions`、`/experiments`；事件 mission.approved、experiment.started、experiment.closed。

## 测试场景

冲突客户信号保留群体；用户撤销同意后源及派生材料不可继续使用；实验没有对照时不自动标因果；已批准任务范围变化重新走决定；客户私有机会不能被其他组织搜索。

## 发布与观察

先以建议/草稿模式启用，重要投入仍由授权人决定。监控来源缺失率、待决策时长与实验数据健康，不按机会数量判成功。对接分析平台由 ZT24/28 负责，本模块定义实验语义。
