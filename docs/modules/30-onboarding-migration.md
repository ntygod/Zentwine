# ZT30｜组织接入、迁移、导出与采用体验

状态：Planned。负责人职责：产品、前后端、集成、安全、平台。依赖模块：ZT02、ZT24、ZT26、ZT27。对应蓝图：18.5、23；完整客户生命周期。

## 目标

让团队可从目标管理、AI 执行、需求变更、交付验证或模型治理进入，再汇入同一数据体系。原生、联邦与渐进迁移可选。客户可以迁入、调整、撤销连接和退出，不靠锁定数据形成壁垒。

## 对象与状态

OnboardingSession、ReadinessCheck、ImportJob(source,mapping,dry_run,cursor)、MigrationPlan、ExportManifest(objects,relations,revisions,artifacts,hashes)、ExitRequest、DeletionReceipt。

默认只读接入，明确授权后开启写入。原文档、附件、作者和来源保留映射；未知格式进入冲突队列，不悄悄丢字段。

## 开发工作包

| ID | 前置 | 开发内容与交付 | 验收标准 |
|---|---|---|---|
| ZT30-01 | ZT02-01、ZT24-01 | 实现组织向导、角色/仓库/Runner/模型配置和授权可视检查 | 不要求一开始连接所有系统；无 Key 可体验明确标识的 Demo |
| ZT30-02 | ZT30-01 | 实现就绪诊断：代码权限、测试基线、数据政策、模型/工具能力、环境 | 每项给真实原因和修复动作；扫描未知不伪称全项目已理解 |
| ZT30-03 | ZT30-02、ZT24-04 | 实现 CSV/JSON/Markdown/外部源导入预检、映射、dry run、冲突与恢复 | 先预览再写入；重复导入不复制对象；历史作者/版本/关系不静默丢失 |
| ZT30-04 | ZT30-03 | 实现原生/联邦权威切换、试点项目迁移、失败回退和教学任务 | 两系统不双向覆盖；切换基线有批准和回退清单 |
| ZT30-05 | ZT30-04、ZT26-04 | 实现完整导出：对象、关系、版本、证据索引、获授权文件与校验和 | 导出可在干净环境重建关系；仅导出本人组织许可数据；不导出 secret |
| ZT30-06 | ZT30-05、ZT27-03 | 实现退出、断开供应商、执行收敛、数据保留/删除、恢复后再清理和退出演练 | 撤权不再同步/启动；删除证明范围真实；审计留痕与敏感内容清除协调 |

## 测试与完成

空组织、已有大量历史任务、重复 ID、未知用户、循环引用、附件损坏、超大导出、断线恢复、供应商撤权及组织注销中运行任务均测试。

采用指标关注首次可验证交付、维护负担和持续使用，不能用完成向导点击数替代价值。教程不把 Demo、Mock、模型自述或旧测试标成真实生产能力。
