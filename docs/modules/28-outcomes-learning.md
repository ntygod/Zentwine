# ZT28｜效果分析、复盘与组织学习

状态：Planned。负责人职责：产品、数据、质量、模型评估。依赖模块：ZT05、ZT20、ZT21。对应蓝图：11.4、12.5、14.5、22。

## 目标

让实际产品结果返回原始目标，并把经验转化为经过验证的技能、规则与测试。允许无改善、恶化、未知、停止和功能下线，不把发布成功包装成产品成功。

## 数据与界面

MetricDefinition(numerator,denominator,window,segment,source)、Outcome(mission,exposure,result,limitations)、FeedbackLink、Retrospective、LearningProposal、ReplayEvaluation、RulePromotion、DeprecationPlan。

看板包括产品结果、团队协调与系统可靠性；展示口径、分组、数据时间、缺失与假设。人工评价与实测工具结果分开，不从键盘/聊天/代码量推断个人价值。

## 开发工作包

| ID | 前置 | 开发内容与交付 | 验收标准 |
|---|---|---|---|
| ZT28-01 | ZT05-05、ZT20-03 | 定义指标口径、效果与发布/实验/目标关系，接入观测端口 | 每个数值能查分母/时间/来源；部署前旧数据不冒充新功能效果 |
| ZT28-02 | ZT28-01 | 实现分组、窗口、缺数、保护指标及效果工作台 | 前后对比不无条件标因果；数据不足保留未知，置信与样本可见 |
| ZT28-03 | ZT28-02 | 汇总协调净耗时、返工、决策等待、交付/恢复与总成本 | 包含人工审核纠错成本；不将 Agent 数/产码量当北极星 |
| ZT28-04 | ZT28-03 | 实现复盘、候选规则/测试/技能提案与源事件关联 | 失败总结不直接改变组织策略；候选材料遵守原权限 |
| ZT28-05 | ZT28-04、ZT21-02 | 实现历史回放、保留集评估、人工批准、灰度与撤回 | 新方法退化能回退；回放不重做真实生产副作用；不能跨客户偷用数据 |
| ZT28-06 | ZT28-05 | 实现功能调整/停止/退役建议及完整目标→结果→学习回归 | 没有效果可关闭目标或创建新研究；删除与权限变化传播到学习材料 |

## 交付与风险

同时提供“有改善”和“数据不足”的示例验收；统计方法版本、口径修订与数据延迟可追溯。高级归因和项目预测属于需评估能力，先建议/模拟，再受控使用，不凭空制造精确数字。
