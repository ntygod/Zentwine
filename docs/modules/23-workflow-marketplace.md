# ZT23｜工作流工作室、技能与扩展生态

状态：Planned。负责人职责：前端、执行、平台、安全、生态。依赖模块：ZT16、ZT21、ZT26。对应蓝图：20.2–20.4。

## 目标

通过自然语言、画布和配置文件定义流程，提供调试、模拟、版本、发布和回退；共享可验证的角色、连接器、工程模板和技能。不是提示词文本市场。

## 对象与协议

WorkflowPackage、WorkflowRevision、SkillManifest(inputs,outputs,permissions,dependencies,tests,owner,license)、ExtensionRelease(signature,digest)、InstallationGrant、SandboxSimulation、RevocationNotice。

画布和配置是同一 AST 的视图，避免往返丢字段。发布包固定依赖和权限。用户批准安装不等于授予所有客户数据访问。

## API 与风险

`/workflow-packages`、`/simulations`、`/skills`、`/extensions`、`/installations`。事件 skill.released、extension.revoked。供应链、许可、付费和用户隐私边界需要负责人核对；平台不代替供应商授予权限。

市场关闭时已固定且允许的内部流程可工作；撤销安全规则优先于缓存包。运行中的撤销依据风险停止/隔离，不能假装瞬间抹除既有副作用。
