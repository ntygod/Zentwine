# ZT08｜原生设计、原型与设计到代码

状态：Planned。负责人职责：设计、前端、Agent 工具、质量。依赖模块：ZT03、ZT04、ZT06。对应蓝图：06.1–06.2。

## 目标

原生支持用户旅程、业务流程、页面结构、交互状态、组件设计和可运行原型；可以连接外部设计源，但不是只存设计文件链接。支持不同模型提出方案，人批准后关联实现。

## 数据、界面和安全

DesignProject、DesignRevision、SceneNode、InteractionEdge、DesignTokenSet、ComponentContract、PrototypeBuild、DesignReview、ImplementationDiff。节点关联需求与验收 ID；预览绑定构建摘要。

页面：旅程/流程画布、状态面板、组件/Token 库、可运行预览、设计评审和差异。生成 HTML/JS 与预览视为不可信代码，放独立来源和环境，不可读取管理站 Cookie。

API `/designs`、`/design-revisions/{id}`、`/prototype-builds`、`/design-reviews`；事件 design.approved、prototype.ready、design.drift_detected。

## 异常与验收

失效字体/资产、组件升级不兼容、外部源撤权、生成含外链、预览访问私网均有处理。设计操作审计保留，失败生成不覆盖已有版本。生成模型不可用时原生编辑、评审和手动原型仍可工作。
