# ZT22｜目标自治、持续执行与受控交付

状态：Planned。负责人职责：产品、执行、安全、运维。依赖模块：ZT05、ZT16、ZT19、ZT20、ZT21、ZT26。对应蓝图：01、13、14.1。

## 终态目标

从明确目标组织长期研究、实施、发布与观察，不只生成建议。辅助、委派、受控交付、持续运营可以按项目/动作混用；人制定授权，不必批准每条普通命令。

## 授权与状态

MissionExecution、DelegationContract(goal,resources,actions,prohibitions,budget,expiry,verification,release,stop/escalation)、AutonomyProfile、TriggerSubscription、PromotionDecision、EmergencyStop。

自治等级由政策与证据系统批准，Agent 只能提出晋级建议。目标改变、数据撤权、模型/技能退化可能强制降级或停止。

API `/mission-executions`、`/delegation-contracts`、`/autonomy-profiles`、`/triggers`、`/emergency-stops`。

## 完成定义与风险

演示依赖维护自动交付、业务规则变更人工升级、保护指标异常停止，以及目标效果不足后重新规划。不可控或高风险环节保持建议模式，但终态入口与验证提升路径存在。

长期工作通过持久对象和执行接力保持连续，不依赖一个无限增长、永远在线的模型会话。公开宣传不得把未经验证的复杂自愈说成确定能力。
