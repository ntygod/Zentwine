# ZT11｜知识、搜索、共同事实与上下文装配

状态：Planned。负责人职责：后端、检索、执行、安全。依赖模块：ZT03、ZT06、ZT18。对应蓝图：12。

## 目标

把组织、产品、项目、任务和执行中的事实连接起来，按当前任务提供最小充分上下文。知识可追溯、有时效、有权限，不是一个装满全部聊天的向量库。

## 对象与接口

Source(uri,hash,acl,retention)、KnowledgeClaim(kind,source,valid_time,observed_time)、Relation、SearchIndexEntry、ContextSnapshot(items,omissions,policy_hash,content_hash)、InvalidationTask。

kind 区分原始记录、推断、建议、批准、观察、已验证和废弃。`/search`、`/knowledge/{id}`、`/context-snapshots`、`/sources/{id}/revoke`。事件 context.created、knowledge.stale、source.revoked。

## 风险和完成标准

索引不是权威库，embedding 故障时允许降级全文/指定原文；无法安全检索时拒绝而不扩大数据。禁止默认跨客户训练。完成需上下文引用、采用与失效测试，并演示撤权中断正在准备的新执行。
