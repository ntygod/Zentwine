# ZT25｜团队协作、客户门户与移动审批

状态：Planned。负责人职责：产品、前端、后端、安全。依赖模块：ZT02、ZT03、ZT04。对应蓝图：02、15.4–15.5。

## 目标

评论、共同编辑、决策、经同意的会议资料、通知和外部验收依附真实工作对象。不是另造一个无上下文聊天软件。个人助手与团队协作分开；Agent 发言明确身份，不伪装成人类同事。

## 对象与入口

Thread(subject_revision)、Comment(anchor,visibility)、Mention、DecisionRequest、NotificationPreference、DeliveryReceipt、MeetingConsent、GuestPortalGrant、ExternalFeedback、MobileApprovalSession。

页面：我的工作/待决策、对象侧栏、交付讨论室、客户预览与验收门户、移动审批。API `/threads`、`/decision-inbox`、`/notifications`、`/guest-portals`。批准最终仍由 ZT02 的版本/身份策略核验。

## 开发工作包

| ID | 前置 | 开发内容与交付 | 验收标准 |
|---|---|---|---|
| ZT25-01 | ZT03-02、ZT02-02 | 实现对象评论、讨论、提及、附件和可见范围 | 私人草稿不自动公开；跨项目提及不能泄漏名称和摘要 |
| ZT25-02 | ZT25-01、ZT04-03 | 实现待决策卡、委派/升级/批量同范围处理及时间提醒 | 卡片显示为什么、版本、影响和权限；沉默不默认批准 |
| ZT25-03 | ZT25-02 | 实现摘要通知、偏好、免打扰、去重与真实送达状态 | 不无限催问；发送与阅读/采用分开；重试不重复发送 |
| ZT25-04 | ZT25-01 | 实现经同意的会议记录导入、候选决定提取与人工确认 | 无同意不采集；摘要不是批准；引用过时方案需核对 |
| ZT25-05 | ZT25-02 | 实现客户/合作方门户、限期预览、反馈和范围内验收 | 外部用户无法枚举内部任务、代码或成员；分享撤销立即阻断新访问 |
| ZT25-06 | ZT25-05 | 实现移动响应式/PWA 决策入口、二次身份验证和跨端 E2E | 小屏能看完整变更与风险；离线批准不执行，联网后重新核验版本和权限 |

## 异常和完成

被删评论锚点、移动旧会话、附件恶意内容、外部分享转发、同一批准多端响应、时区提醒均测试。业务方可只看验收信息，开发者不被迫处理全组织通知。

关闭外部消息连接器后站内协作仍可用。客户门户不是公开展示整个项目，公开邀请和文件访问使用独立授权与审计。
