# ZT10｜项目组合、联合容量与项目沙盘

状态：Planned。负责人职责：产品/项目、后端、前端、数据。依赖模块：ZT03、ZT04。对应蓝图：07、14.2。

## 终态范围

原生项目与项目群、里程碑、工作包、迭代、看板、日历、时间线、依赖、风险/问题/决定、资源容量、预算、计划基线和情景推演。支持持续工作流，不强制所有维护工作有截止项目。

## 数据与状态

Project、Portfolio、WorkPackage、PlanRevision、Milestone、Dependency、Calendar、CapacityPool(human_review/decision/agent/environment)、Reservation、Risk、ScenarioBranch、SimulationResult。

工作包完成条件使用验收与证据；Blocked 仍计在制品。Scope/承诺日期变化走决定；低风险队列重排可按既定规则执行。时间线显示意向、预测、承诺区别。

API `/projects`、`/work-packages`、`/plans`、`/capacities`、`/scenarios/{id}/simulate`、`/scenarios/{id}/adopt`。

## 验收与观察

覆盖依赖死锁、评审超载、跨区域工作时间、取消已预留资源、变更基线、模拟随机种子和参数回放。模拟输出注明假设、样本和不确定性，模型生成的估算不是对客户承诺。

监控周期、等待和可执行队列，不按故事点或代码量排列个人。计划算法有版本与撤回，关闭自动重排不影响手动管理。
