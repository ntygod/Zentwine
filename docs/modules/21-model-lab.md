# ZT21｜模型实验室、评估与路由

状态：Planned。负责人职责：模型评估、质量、执行、数据。依赖模块：ZT12、ZT16、ZT19。对应蓝图：08.6、20.1、22。

## 目标

选择适合本团队具体任务的模型/角色/工具组合，并在升级时检测退化。不是固定品牌排名，不把模型数量、聊天轮次或供应商宣传分数当成质量。

## 数据与策略

BenchmarkDataset(consent,split,task_type)、EvaluationConfig(model/runtime/role/tool/environment_versions)、EvaluationRun、CaseResult、RoutingPolicy、CanaryAllocation、DriftSignal。记录样本数、任务难度、人工修正、延迟、费用和错误类别。

路由先筛数据政策、身份、工具/基座兼容、预算和资源，再在允许集合内比较任务表现。fallback 不能把敏感材料转给未获授权供应商。

## API 与观察

`/evaluation-datasets`、`/evaluations`、`/routing-policies`、`/model-rollouts`。事件 evaluation.completed、routing.policy_approved、model.degraded。评估结果不直接晋升自治权限，需 ZT22 政策流程。

## 风险

评测污染、模型裁判偏差、不同任务不可比、供应商版本别名改变、价格不确定。使用可执行验证与抽样人工核验；费用采集不等于账单，最终经 ZT26 对账。
