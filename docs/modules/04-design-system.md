## 产品目标

建立可长期使用而非展示大屏的原生界面。按角色渐进显示经营、交付与治理功能；Studio 共享组件/身份但使用独立布局。历史 UI 图仅视觉参考，纠正伪造评分、进度不一致、过时模型、错误日期和合规宣称。

## 界面和状态

提供导航、组织切换、命令面板、搜索、对象详情、表格、看板、图节点、版本差异、决策卡、预算卡、状态标签与证据链接。所有组件支持 loading/empty/error/forbidden/stale/offline；运行中、停止中、未知不使用同一绿点。

语言默认中文、资源可本地化；时间统一后端 UTC、展示时区可切换；全局快捷键不破坏中文输入法。可见数值必须有来源、分母或估计标记。
