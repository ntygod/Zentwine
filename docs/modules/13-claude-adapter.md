# ZT13｜Claude Agent SDK 适配

状态：Planned，未进行真实供应商测试。负责人职责：执行工程、安全、质量。依赖模块：ZT12、ZT15。对应蓝图：08、18。

## 目标和依据

使用官方 Claude Agent SDK 作为执行基座，映射到 Zentwine RuntimeAdapter，而不是重造模型工具循环或嵌入 Claude Code 终端皮肤。API 身份、条款、项目配置加载和品牌按选定版本核对；未经批准不提供个人 claude.ai 登录/额度复用。UI 使用独立 Zentwine 品牌与允许的 Claude Agent 描述。[S01]

## 适配映射

StartRun → SDK 配置与指定工作区；SDK 事件 → 平台统一工具/状态/产物事件；工具权限/用户输入 → 版本绑定 ApprovalRequest；native session → 私有 NativeSession 映射。上下文注入引用固定快照，环境 secret 只由 Runner 受控提供。

用户 home、全局插件和仓库配置不默认信任。逐项确认 SDK 会加载哪些 settings、hooks、skills、MCP；平台只启用经过许可的集合。Hook 检查是补充，操作系统隔离和工具策略是最终控制。

## 测试清单与升级

覆盖无凭据、无权限模型、被污染项目配置、工具拒绝、供应商限流、审批时断线、重启会话失效、磁盘满、重复事件、晚到用量。SDK 升级先影子/隔离回归，不能对现有 Run 热换协议。

ZT13-06 需要 ZT14-06 的单适配真实报告作为输入，但两者共同联调由 ZT16-06 验收；不形成互相等待的循环。若无法获得供应商权限，交付适配代码与 skipped_live 报告，整个真实异构门禁仍保持未通过。
