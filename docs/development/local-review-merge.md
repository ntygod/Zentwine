# 多份文件意见的预览合并

ZT18-01-F / Issue #75。先按 [文件意见指南](local-review-notes.md) 导入原比较报告并添加或导入当前意见。逐份合并其他审阅者的意见，仍使用原 v1 JSON，不上传、不自动保存、不改变代码或 PR。

## 先预览，再确认

选择「待合并意见 JSON」，点击「预览意见合并」。选择文件本身不读取正文。预览列出新增、重复和冲突，每页最多10条，当前意见和已准备下载保持不变。

同一ID且路径、类型、署名、正文全部相同才去重；不同ID即使正文相同也作为新增保留。同一ID任一字段不同就是冲突，展示当前与导入两侧，必须逐条选择「保留当前意见」或「采用导入意见」。不默认选择、不按时间戳推断最新，不自动重命名或创建身份。

所有冲突包括其他分页上的冲突都选择完毕后，点击「确认合并意见」才一次性更新。当前意见顺序保留，采用导入版本占原位置，新ID按导入顺序追加。空文件中的空意见集不会清空当前意见。继续逐份预览可汇总多人的意见；不支持批量目录读取或跨原报告合并。

确认后重新准备下载，导出仍为原v1意见文件，可由原意见导入入口读取。旧的「导入文件意见」仍仅允许空意见集导入，不会覆盖已有意见。合并不是语义消歧、审查批准、作者认证或持久Review；意见与自填署名继续标为未认证。

## 取消、失败与限额

预览期间暂时禁用添加、移除、准备新下载，防止基线变化；取消预览恢复编辑并保留未添加草稿及已准备下载。选择另一份文件会取消在途读取或旧预览并清空旧冲突选择；取消、超时、格式/绑定错误不更改当前意见。显式「清除全部意见」仍清除当前集并废弃预览。

确认成功会清空未添加草稿并撤销旧下载URL；确认失败保留当前集和预览，允许改选冲突或取消。原报告替换、清除、关闭、刷新及离开页面仍丢失内存意见，不保留跨会话预览。

每个输入仍不超过512KiB及100条，复用原严格解析和精确报告字节SHA-256/对象格式/commit/tree绑定。合并后最多100个唯一ID；超过即拒绝预览。最终结果还须通过原标准序列化512KiB上限，路径和JSON转义可能导致两个合格文件组合后超限，此时确认整次失败，没有部分写入。

冲突选择不改变原报告绑定。相同ID不证明同一作者；结构自洽的伪造输入仍可能通过，不能交给Agent自动执行。下载内容也可能包含敏感意见。

## 接口与验证

client公开 `previewRepositoryReviewMerge(session, current, incomingJson)` 和 `applyRepositoryReviewMerge(session, preview, current, choices)`。choices是每条冲突恰好一个 `{id, keep: "current" | "incoming"}`。预览为冻结快照；应用要求原会话对象和完整当前意见（含顺序）仍匹配预览基线。重建、跨会话或过期预览、缺失/多余/重复选择均拒绝。这是内存一致性检查，不是持久CAS、身份令牌或跨进程锁。

构建后运行 `node --test tests/repository-review-merge.test.mjs`；浏览器运行 `pnpm exec playwright test tests/browser/repository-review-merge.spec.ts`。原意见导入、下载和报告读取测试全部保留。设计见 [ADR-038](../adr/ADR-038-local-review-merge.md)，过程见 [执行记录](../tasks/ZT18-01-F-execution.md)，结果见 [验证报告](../testing/zt18-01-f-report.md)。
