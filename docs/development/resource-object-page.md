## 使用

按既有组织开发指南启动身份/策略/组织服务后，从“组织工作台 → 可访问资源”点击有权读取的条目。深链为 `/org/<组织UUID>/workbench/objects/<资源UUID>`。路径严格匹配小写UUID，不接受外部跳转、附加段或编码路径；开发宿主按现有SPA回退提供页面，生产回退/API分流仍未部署。

先读取能力、会话及当前成员，再调用现有 `GET /api/v1/orgs/:orgId/resources/:resourceId`，没有新服务端接口。响应严格核对组织/资源ID、资源类型/元数据、目录版本、成员版本、策略版本及allow读取判定；错配不展示内容。访客仅能读取明确共享的资源；目录列表出现过的ID不构成授权。其他组织深链必须用户确认切换，成功后保留该资源深链；切到别的组织不复用原对象ID。

## 界面语义

“正式记录”只展示真实目录登记：资源/组织ID、可见范围、敏感级别、登记负责人和目录版本。目录项不是该项目/工作包的完整业务对象，目录版本不是内容修订或摘要。缺负责人明确未登记，不根据当前用户推断。原有资源读取接口提供的字段不新增数据权限。

“协作对话”与正式记录分区，当前对话服务未接通，不展示模拟消息或可提交输入框。侧栏保留版本、证据、活动和内容决策槽位：只展示现有目录版本，其余明确“尚未接通”，不是“零条记录”。不把组织审计伪装成本对象历史。

“查看读取判定”打开原生模态抽屉，展示此次资源读取的对象版本、组织/对象范围、实际读取身份、成员与策略版本以及UTC判定时间。标题明确“非批准”，reusable=false。打开或关闭抽屉不提交命令；没有内容批准、写入或执行按钮。持续停留不会续期授权，时间仅为历史事实展示。

## 状态与布局

延用Workbench请求代次与Abort策略：重读/切换先移除旧数据，晚响应不能填回；离线、隐藏、pagehide清空，恢复窗口/网络后重新核验。抽屉随受保护子树卸载关闭。持续可见且没有新请求时不承诺实时撤回；截图与外部副本不可收回。

布局默认窗口内存，用户点击“记住布局”才写入固定key `zentwine.ui.object-layout.v1`，仅 `{schema_version:1,density:comfortable|compact,inspector:shown|hidden}`。此浏览器共享的外观偏好，不包含账号、组织、资源标识、查询、当前页、正文、令牌、对话或权限。坏数据/未来schema/超限/存储拒绝降级默认，不渲染原始值也不自动覆盖；配额失败明确提示仅窗口内存。重置只移除此key，不删除其他站点数据。刷新仅恢复外观，仍重新获取受保护数据；没有跨设备同步。
