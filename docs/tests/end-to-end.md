# 端到端验收场景

全部状态：NotRun。此处定义待实施测试，不是已执行报告。每个场景记录 build/commit、环境、模型/基座/策略版本、执行时间、真实结果、证据 URI 与 reviewer。缺凭据/环境标 Blocked 或 Skipped，不记 Pass。

## 测试执行模板

场景 ID、责任人、日期、环境和 build；输入/规格/政策/模型版本；实际操作；期望与实际差异；自动报告/截图/日志摘要；费用；数据清理；结论 Pass/Fail/Blocked/Skipped；评审人。任何空证据不能自动 Pass。
