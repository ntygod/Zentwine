# 开发与维护脚本

## 适用范围

继承 [根约定](../AGENTS.md)。命令从仓库根目录运行；入口参数、退出码、副作用和清理必须可验证。

测试只处理用户明确指定的临时/合成资源；不猜测真实仓库、业务库或凭据。禁止 shell 拼接不可信参数，拒绝越界路径并给子进程设置截止与清理。不要自动执行输入目录的代码。

本地 Git 读取端口与仓库维护工具不是同一权限边界：前者不联网，后者的分支清理需显式授权且默认 dry-run。见 [本地读取](../docs/development/local-repository.md) 与 [维护记录](../docs/maintenance/README.md)。

Harness 路由/校验本身不启动 Agent、联网或执行文档里的命令。新增指南要更新 manifest，并补正反例。

## 验证

运行对应脚本测试、`pnpm check`、`pnpm test:harness`。质量/迁移脚本还需 `pnpm test:quality`；所有历史测试与 gate 保持。生产工具链由根配置决定，工具缺失须明确失败，不能伪造环境通过。
